# Incident Response Policy

## Objective
To provide a structured process for handling security incidents.

## Incident Lifecycle

### Identification
Detect and report security incidents.

### Containment
Limit the impact of the incident.

### Eradication
Remove the root cause.

### Recovery
Restore affected services.

### Lessons Learned
Document findings and improve controls.

## Roles

### Security Team
Investigates and coordinates response.

### Developers
Assist in remediation.

### Project Management
Coordinates communication and reporting.
