# Incident Response Plan

## Objective

Provide a structured response to security incidents.

## Incident Lifecycle

1. Identification
2. Containment
3. Eradication
4. Recovery
5. Lessons Learned

## Severity Levels

### Critical
System compromise or data breach.

### High
Privilege escalation or major vulnerability.

### Medium
Limited impact vulnerability.

### Low
Minor security issue.

## Review

All incidents shall be documented and reviewed.
